# Zolushka.krg

Премиальный RU/KZ-сайт салона красоты в Караганде на Next.js App Router.

## Возможности

- каталог подтверждённых услуг и цен;
- конструктор записи в обычном формате, в 4 и 6 рук;
- локальный пошаговый сценарий записи без отправки персональных данных;
- страницы мастеров, портфолио, контактов и политики конфиденциальности;
- адаптивная вёрстка, доступность и SEO для RU/KZ;
- подготовленная архитектура для будущего подключения реального расписания и CRM.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run lint
npm run typecheck
npm run build
```

## Cloudflare Workers

```bash
npm run preview
npm run deploy
```

Публичная версия: https://zolushka-krg.sites-plus-portfolio.workers.dev

Изображения портфолио и специалистов являются иллюстративными. Форма записи работает локально и не создаёт фактическую запись в салон.
